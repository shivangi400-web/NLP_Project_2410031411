About Number Expression Extraction

About the project

NumiLex is a number expression extraction system designed to automatically identify numeric phrases in unstructured text and classify them according to their meaning and context.

The application currently supports six categories: Quantity, Percentage, Currency, Measurement, Ranking, and Date. The workflow combines pattern detection, contextual analysis, and explainable rule-based classification to keep decisions transparent and easy to understand.
